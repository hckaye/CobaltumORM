# CobaltumORM

CobaltumORM is a .NET / C# ORM whose main target is PostgreSQL. SQL stays explicit while supported queries are checked at build time against the schema built from migrations. The compiler generates type-safe query APIs and result types without connecting to a database.

Migration and compile-time SQL analysis support PostgreSQL, MySQL, SQLite, SQL Server, and Oracle. Queries can use the incremental source generator or C# files generated explicitly by the command-line tool.

Installation, configuration, examples, and current limitations are documented in the [English README](https://github.com/hckaye/CobaltumORM/blob/main/README.md) and [Japanese README](https://github.com/hckaye/CobaltumORM/blob/main/README.ja.md).
